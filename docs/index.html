Ariadne

El hilo para no perderte en un codebase, tuyo o de alguien más.

ariadne generate .  →  un diagrama interactivo, autocontenido, en un solo HTML

Genera el mapa de tu proyecto con un solo comando

Ariadne analiza un proyecto (árbol de archivos, dependencias reales entre ellos, clases y métodos, historial de git) y arma un diagrama HTML interactivo. Nada de dibujarlo a mano ni de que quede desactualizado, se regenera cada vez que corres el comando.

Usa heurística de texto en vez de un parser AST real, por eso soporta 15 lenguajes distintos sin necesitar una gramática propia para cada uno. Se documenta a sí misma con la misma herramienta: este sitio incluye su propio diagrama más abajo.

El hilo de Ariadna no dibuja el laberinto, solo te deja encontrar el camino de vuelta. Mismo principio, aplicado a un repositorio

Lo que hace, y lo que no

+ Diagrama HTML interactivo y autocontenido, funciona con file:// o en GitHub Pages
+ 15 lenguajes: referencias entre archivos, clases/métodos/atributos, dependencias declaradas
+ Autor y fecha de git por archivo, colorear por antigüedad, "ver historial", link a documentación propia
+ Exporta a PDF/LaTeX/RTF/XML vía Pandoc, desde el mismo grafo
- No es un parser AST real: es heurística de texto, se rompe con macros o metaprogramación poco convencional
- No hace blame línea por línea: para eso, abre el archivo directo

Navega la documentación desde aquí

Este es el propio diagrama de Ariadne, generado por Ariadne, y es interactivo de verdad: colapsa carpetas, cambia de orientación, activa filtros. Los nodos marcados con ★ tienen una página propia. Selecciona uno y usa "Ir a documentación" en el panel derecho para saltar directo al contenido, o sigue leyendo las 4 páginas de abajo en orden.
